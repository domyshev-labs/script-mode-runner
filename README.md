# Script Mode Runner

Нативное menu bar приложение для macOS 14+, которое запускает заранее настроенные группы команд и показывает их вывод.

## Быстрый старт

1. Создайте `~/.config/script-mode-runner/config.yaml` по образцу из `Examples/config.yaml`.
2. Соберите и запустите: `swift run ScriptModeRunner`.
3. Откройте значок терминала в строке меню.

Команда может быть задана безопасной парой `executable`/`arguments` либо строкой `command`, выполняемой через shell. `yarn`, `npm`, Python, локальные бинарники и любые другие программы обрабатываются одинаково.

Для полноценной `.app`-сборки, подписи и нотарификации потребуется Xcode. Текущая Swift Package сборка предназначена для разработки и тестов движка.

## Принятые правила MVP

- режимы взаимоисключающие внутри одной верхней вкладки;
- переход между верхними вкладками сам по себе не деактивирует режим;
- reload сохраняет уже запущенные процессы, но интерфейс использует новую конфигурацию;
- при штатном выходе приложение останавливает управляемые группы процессов;
- в памяти хранится не более 5 МБ вывода на процесс.
